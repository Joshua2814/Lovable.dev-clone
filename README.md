# Lovable.dev-clone

A frontend-only Lovable-inspired dashboard and project editor built with React 19, TypeScript, Vite, lucide-react, and local mock state.

## Run
```bash
npm install
npm run dev
```

## Included
- High-fidelity dark dashboard with collapsible sidebar, workspace switcher, command/search affordances, recent projects, daily credits, hero prompt composer, project gallery, grid/list view, filters, sorting, starring, and project creation.
- Project editor with global top bar, Build / Plan / Ask modes, chat/agent rail, thinking/tool badges, composer attachments, slash skills menu, responsive preview controls, inspector overlay, Code / Files / History surfaces, and More surfaces.
- Cloud, Analytics, Settings, SEO, Security, Payments, AI Gateway, and Agent Integrations are represented as frontend mock surfaces.
- No backend or cloud sandbox is assumed; state is local and structured for future service binding.
